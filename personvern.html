Personvern og informasjonskapsler

Oppdatert 11. september 2026. Denne siden forklarer behandlingen av opplysninger på cøv49.no / cov49.no.

Når du kontakter oss

Nobello AS bruker navn, e-post, telefon, boligønske og eventuell melding for å svare på din forespørsel og følge opp interessen for prosjektet. Henvendelsen deles med ansvarlig megler hos PrivatMegleren Dyve & Partnere. Unngå å skrive sensitive opplysninger i meldingsfeltet.

Skjemaet sendes via nettstedets server hos Vercel og e-posttjenesten Resend. Opplysningene brukes til den oppfølgingen du ber om. Markedsføringssamtykket nedenfor er frivillig og er ikke et vilkår for å kontakte oss. Opplysninger beholdes så lenge de er nødvendige for oppfølgingen og eventuelle dokumentasjonskrav; ta kontakt for spørsmål om sletting av din henvendelse.

Valgfri besøksstatistikk

Når du velger statistikk, lastes Google Analytics. Tjenesten mottar blant annet sidebesøk, tekniske nettleseropplysninger og handlinger som registrert interesse og prospektnedlasting. Vi bruker dette til å forstå hvordan nettstedet brukes. Google kan sette informasjonskapsler som _ga og _ga_… for å kjenne igjen nettleseren. Kontaktfeltene i skjemaet sendes ikke som hendelsesparametere.

Valgfri markedsføring

Når du velger markedsføring, lastes Metas piksel. Meta mottar blant annet besøkte sider, nettleser- og nettverksopplysninger og hendelser som registrert interesse og prospektnedlasting. Meta kan knytte dette til din Meta-konto og bruke data til måling, annonsetilpasning og forbedring av egne tjenester. Informasjonskapslene _fbp og _fbc kan brukes til matching og annonsemåling. Nobello sender ikke navn, telefon, e-post eller fritekst fra skjemaet som pikselparametere.

Samtykke styrer disse valgfrie tjenestene. Ved «Kun nødvendige» lastes verken Google Analytics eller Meta-pikselen. Når du trekker et samtykke tilbake, stoppes videre måling for formålet og målingskapsler på dette nettstedet fjernes så langt nettleseren tillater. Dette sletter ikke automatisk data som allerede er mottatt av leverandørene.

Ditt valg og lokal lagring

Vi lagrer valget og tidspunktet lokalt i nettleseren under cov49Consent, i inntil 180 dager. Vi spør på nytt når valget utløper eller formålene endres. Visningsvalg, som lyst/mørkt tema og lukkede hjelpetekster, kan også lagres for at nettstedet skal fungere slik du har valgt. Disse brukes ikke til annonsemåling.

Leverandører og dine rettigheter

Leverandørene kan behandle data utenfor EØS. Se deres opplysninger om behandling, lagring og overføringsgrunnlag: Meta, Google, Vercel og Resend. Kart eller eksterne lenker kan føre til tjenester med egne personvernregler.

Kontakt Nobello på sf@nobello.no for spørsmål eller forespørsler om innsyn, retting, sletting eller andre personvernrettigheter. Du kan også kontakte Datatilsynet. Megler kan nås på jorgen.ek@privatmegleren.no.

Ditt valg av informasjonskapsler

Med ditt samtykke bruker vi Google Analytics til besøksstatistikk og Meta-pikselen til å måle annonser og tilpasse markedsføring. Meta kan knytte besøk og handlinger til din profil og bruke data til egne tjenester. Du kan bruke nettsiden og kontakte megler uten å godta dette. Les om personvern og informasjonskapsler.

Tilpass valget

Valget lagres i denne nettleseren i inntil 180 dager. Du kan endre det nederst på siden.
